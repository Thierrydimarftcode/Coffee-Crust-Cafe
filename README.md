# ☕ Kopi & Crust Café - Simple Web

Proyek website sederhana untuk **Kopi & Crust Café**. Website ini dibuat menggunakan HTML5 dan CSS3 murni (*vanilla*) untuk menampilkan profil kafe, daftar menu makanan & minuman beserta harganya, serta formulir pemesanan *on-the-spot*.

---

## 📌 Fitur Utama

- **Halaman Profil / Landing Page (`Coffee & Crust Cafe.html`)**: Informasi tentang Kopi & Crust Café dan suasana tempat nongkrong.
- **Daftar Menu & Harga (`daftar_menu.html`)**: Tabel rapi yang menampilkan daftar kopi, pizza, dan roti beserta harganya.
- **Formulir Pemesanan (`pesan.html`)**: Form untuk memesan makanan dan minuman secara langsung di tempat (*On The Spot*).
- **Desain Warm & Responsive (`style.css`)**: Tampilan bernuansa hangat khas kafe (*espresso, warm wood, cream*) yang sudah responsif untuk perangkat mobile maupun desktop.

## 🛠️ Teknologi yang Digunakan
HTML5: Struktur halaman web dan form.

CSS3: Styling, tata letak (layout), warna tema, dan efek tombol responsif.

Google Fonts: Font Poppins dan Playfair Display untuk tampilan estetis.
